# Release notes
## 1.1.0
Released 08 November 2026 for The Long Dark 2.55 and 2.60+.

- Updated for The Long Dark 2.60+ (including Iron Road DLC).
- Added option to show your position on the map (enabled by default).
- Added option to center the map on your position (enabled by default).
- Added default values to the mod settings UI descriptions.

**Update note:**
- If you set "_Enabled: no_" in the mod settings, it'll get reset since the option was split.
